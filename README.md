# Anagram Generator
A Java application that generates full and partial anagrams of user-provided words and searches for valid matches using a Binary Search Tree (BST) dictionary.

## Features
- Generates unique full-length anagrams using recursive backtracking.
- Generates partial anagrams by creating subsets and permuting them.
- Eliminates duplicate anagrams efficiently.
- Stores dictionary entries in a Binary Search Tree for fast lookup.
- Supports translation lookup from external dictionary files.
- Includes complexity analysis and runtime benchmarking.
- Provides automated and manual edge-case testing.
